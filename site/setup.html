Set it up

A few steps from nothing to live progress bars. Already use Claude Code? Skip to step 3.

Install Claude Code Sign in Add Agent Progress Using it Settings How it works Troubleshooting

1Install Claude Code

Open a terminal. On a Mac, press Cmd + Space, type Terminal and press Enter. On Windows, open the Start menu and type PowerShell. Then paste the one line for your system below and press Enter. Full details are in Anthropic's setup guide.

macOS, Linux and WSL

curl -fsSL https://claude.ai/install.sh | bash

Windows (PowerShell)

irm https://claude.ai/install.ps1 | iex

Homebrew

brew install --cask claude-code

Open a new terminal window and check it worked. You should see a version number.

claude --version

2Start it and sign in

Go to a folder you want to work in, then start Claude Code. Replace your-project with your folder, or use cd ~/Desktop to just try it out. The first time, a browser window opens so you can sign in with your Claude account. When you come back, you'll see a box to type in: that's the Claude Code prompt.

cd your-project
claude

3Add Agent Progress

In the Claude Code prompt from step 2, paste this line and press Enter. It starts with / because it's a Claude Code command, not a terminal command.

/plugin install agent-progress --marketplace ishmael07/agent-progress
  1. Press y when it asks to add the marketplace.
  2. Press Enter to install it for your user, so it works in every project.
  3. You'll see Installed agent-progress. It's active right away. Now try step 4.

Prefer your normal terminal, outside Claude Code? This does the same thing:

claude plugin install agent-progress --marketplace ishmael07/agent-progress

In the Claude desktop app: click + next to the prompt box, then Plugins, Add marketplace with ishmael07/agent-progress, then Add plugin.

4Try it

Ask for something that uses a few agents at once, for example:

Use 3 agents in parallel to look around this project and tell me how it's organized.

A bar appears above the prompt for each agent the moment it starts. Click a row to see how that agent helps with your request, plus its checklist.

Using it

The bars above the prompt

One bar per running agent: which agent it is (its name, or Agent 1, Agent 2…), what it was asked to do, % done, the step it's on and time left. Finished agents turn green and leave after 30 seconds. Click a row to open it, and click the summary line on top to open the table.

Commands

CommandWhat it does
/progressShow the live bars right in the chat and open the table on the side, with an overall bar when more than one is running. Works even while Claude is busy.
/progress explainOpen every row at once. Run it again to fold them.
/progress offStop the bars from popping up on their own. Remembered across sessions. /progress still shows them anytime.
/progress onTurn them back on (/progress toggle flips it)
/progress clearRemove finished agents

Settings

Open /config and find agent-progress.

SettingDefaultWhat it does
Ask agents for a step listOnAdds a short note to each subagent's instructions asking it to share a plain step list and check it off. This is what makes the % accurate.
Plain-language summariesOnWhen an agent doesn't say how it helps, Agent Progress writes one sentence about it using Claude Haiku.
Show bars above the promptOnThe live bars above the prompt. The table works either way.
Notify when agents finishOffA system notification when all agents are done.

How it works

Claude Code doesn't report a % for agents, so Agent Progress works it out.

  • With a step list (the default), each subagent gets a small progress tool and is asked to share its plan and check steps off. The % follows the steps. Within a step the bar keeps moving at the agent's own pace, but never passes the next step's mark.
  • Without one, the bar is an estimate from the agent's activity, marked with ~.
  • Time left appears after an agent finishes its first step, based on how long its steps take. Before that you see how long it has been running.

Cost and privacy

The step-list note adds a few tokens to each subagent. With summaries on, an agent that doesn't explain itself costs one small Claude Haiku call. That call includes your latest request and the start of that agent's instructions. It goes through your own Claude Code session, like any other request. Nothing is sent anywhere else. Turn either off in /config.

Update or remove

Update to the latest version, then restart Claude Code:

claude plugin update agent-progress

Remove it:

claude plugin uninstall agent-progress

Troubleshooting

No bars show up

Bars appear only while agents run. Ask for parallel agents to test it. If still nothing, run /progress on, check that Show bars above the prompt is on in /config, and make sure Claude Code is up to date (claude update). Agent Progress uses plugin mods, an early-access part of Claude Code.

The % has a ~ in front

That agent didn't share a step list, so its bar is an estimate. Custom agents with a fixed tool list can't use the progress tool.

No time left yet

It shows after an agent finishes its first step. Until then you see how long it has been running.

The table doesn't open

In a narrow terminal, /progress prints the table as text instead. Make the window wider to see the table in a side panel.
